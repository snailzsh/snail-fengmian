# 通用部件（任何模式、任何风格都能拼进去）

## 1. 姿态库（出镜用，来自 xhs 和 gbro）
人物姿态要**和标题、主体有呼应**：手指的方向、眼睛看的方向，最后都要落在标题或主体上。

| 姿态 | 适合 | 提示词写法 |
|---|---|---|
| 指向物件 | 揭秘、调查 | `低头看向{物件}，右手食指点在{物件的关键处}` |
| 托下巴思考 | 提问、反常识 | `一只手托着下巴，眼睛斜向上看着标题，嘴角带一点笑` |
| 举起道具 | 种草、展示 | `一只手把{道具}举到脸侧，另一只手指着它` |
| 看向标题 | 观点、口播 | `身体朝向画面另一侧，眼神看向标题所在的区域` |
| 直视镜头 | 质问、强观点 | `正面直视镜头，眉头微皱，像在当面提问` |
| 双手持对比卡 | 前后对比 | `双手各拿一张卡片，前面一张举近镜头` |
| 摊手 | 无奈、吐槽 | `双手摊开，耸肩，表情无奈带笑` |
| 竖大拇指 | 推荐、正向 | `一只手竖大拇指，表情自信` |

表情默认**轻微惊讶**：眉毛轻扬、嘴微张、眼睛不要瞪大。用户另有偏好就按用户的。

## 2. 证据卡写法（来自 oil）
- **只留 2–3 个关键元素**，比如标题、一个关键数字、一两行原文，其余删掉。整张卡露出 80%–95%，略微倾斜。
- **关键数字放大**：查看数、金额、百分比做成 ≤8 字的大号数字，一眼能读；英文正文只当质感。
- **英文产品名、文章标题用衬线体**，显得高级；中文用超粗黑体。
- 卡片和标题用轴线对齐，不要随便摆。
- 证据必须是片中真出现的截图或数据，不伪造。
- 提示词写法：`附带图N是片中的{截图}，重组成一张干净放大的界面卡：只保留「{标题}」和「{数字}」，删掉其他噪音，略微倾斜，露出约 90%，带柔和投影`

## 3. 标题处理（按风格挑一种，不要叠太多）
| 处理 | 效果 | 写法 |
|---|---|---|
| 关键词色块高亮 | 清楚、杂志感（oil） | `「{关键词}」下面垫一块柔和珊瑚色高亮底，问号同色` |
| 白字 + 黄色符号 | 稳、冲击（simon） | `白色超粗黑体，问号/数字用黄色` |
| 渐变大字 + 发光 | 最抢眼（gbro） | `白色到暖橙色渐变，带一点外发光，问号亮黄色` |
| 白字细黑描边 | 压在复杂画面上也清楚 | `白色超粗黑体带细黑描边` |
| 黄底黑字色块 | 小红书干货感（xhs） | `黑色超粗黑体，字后面垫黄色 #FFD93D 色块` |
| 手写毛笔 | 温度、人文 | `{颜色}毛笔手写体，有粗细变化和飞白` |

通用：主标题只出现一次；两行、每行 ≤5 字；**每个字都必须完整可认，任何元素最多压到字形外缘**。

## 4. 标签和点缀
- **黄色实体胶带或贴纸**写副标题，≤10 字（simon）。
- 小索引标签最多 3 个，每个 2–5 字（oil）。
- 点缀元素（发光节点、数学符号、小火花、星星）总数 ≤5，只做点缀（gbro）。
- 右上角 22%×12% 默认留空；风格本身要在那里放东西（比如期数）时，告诉用户二选一。
