# 出镜·实物（simon 调查封面 + 人物反应）

样张：（出镜样张带作者本人头像，没放进仓库）（台灯、旧作业本上画着蘑菇云，人低头指着本子，表情轻微惊讶）。

## 骨架
- 背景：深炭灰到暗墨绿（片子色调偏冷时可以换深海军蓝），有摄影感，一盏实体光源打出明暗。
- 主体物件：**把片子的比喻做成一个能摸到的东西**（作业本、账本、合同、零件），放在中下部，占 30–40%。物件上可以夹或贴片子里的真实画面（照片、截图打印件）。
- 人物：半身，在物件后方或一侧，姿态从 `building-blocks.md` 姿态库挑（默认「指向物件」），**手指和视线最后都落在物件或标题上**，表情轻微惊讶（眉毛轻扬、嘴微张）。
- 标题：上三分之一，两行白色超粗黑体，关键符号（问号、数字）用黄色。
- 黄色实体标签（胶带或贴纸）写副标题，贴在物件上。
- 右上角 22%×12% 留空。

## 换风格
模板里「视觉语言」那行、标题和背景的颜色是默认风格。要换就用 `styles.md` 的风格段替换，结构不动。姿态、证据卡、标题处理见 `building-blocks.md`。

## 横版（4:3 / 16:9）
- 标题放左侧 45%，两行或三行；人物和物件在右侧，人物视线朝标题方向。
- 不要拿竖版裁切。
